## Objective

Pure, framework-free types and branded primitives that make the arithmetic downstream hard to get
wrong.

## Requirements

- **Branded primitives** for `Probability`, `Price`, `Shares`, `Usdc`. They exist for one reason:
  to stop someone multiplying a probability by a price and getting a number that type-checks. A
  brand that can be bypassed by a bare arithmetic operator has failed at its only job — give each
  a constructor that validates its range (`Probability` and `Price` in [0,1]) and make the raw
  numeric type unreachable without one.
- The domain interfaces from `POLYMARKET_DOMAIN_MODEL.md`: `Market`, `OrderBook`, `BookLevel`,
  `FillEstimate`, `SimulatedPosition`, `Forecast`, `Recommendation`, `FeeConfig`.
- **`OrderBook` must encode the normalization contract in its own doc comments**: `asks[0]` is the
  best (lowest) ask, `bids[0]` is the best (highest) bid, both **after** `mapOrderBook` reverses
  the upstream arrays, which arrive worst-price-first on both sides. See §2. This was recently
  corrected — the doc previously claimed bids arrived descending, and they do not.
- **`tokenId` is a string**, always, everywhere. 77 digits, exceeds `Number.MAX_SAFE_INTEGER`.
- `FeeConfig.source` must distinguish a rate read from the market object from a category fallback,
  because the UI is required to label an estimated fee. An absent upstream fee field is **not** a
  zero rate, and the type should make representing it as one awkward.
- The **error code union** from `docs/04-architecture/API_CONTRACTS.md` — a closed union of codes,
  never strings.
- Type-level guards and predicates as needed. No runtime validation library here: zod lives at the
  upstream boundary in `src/polymarket`, and nowhere else.

## Purity is enforced, not requested

`src/domain` imports **nothing internal** and has no React, no Next, no I/O, no `any`. ESLint
enforces this and a violation fails CI. If you find yourself wanting an import, the thing you want
belongs in a different module.

## Acceptance criteria

1. `pnpm typecheck && pnpm lint && pnpm test` green, zero warnings.
2. Every type named above exists and is exported from the `src/domain` barrel.
3. A test proves a branded primitive cannot be constructed from an out-of-range number, and that
   two different brands are not mutually assignable.
4. A test proves a 77-digit token id round-trips through the domain types with no precision loss.
5. No import of React, Next, or any I/O anywhere in `src/domain`.
