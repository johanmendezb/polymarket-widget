## Scope: T7.1 only — the accessibility and copy pass

E4's four widget states are built and on your branch. You are auditing and fixing them, not
rebuilding them. Do **not** touch the read path, the simulation layer or the AI layer.

Do **not** do T7.2 (deployment and secret verification) — that needs T5.4, which is being built
in parallel right now.

## What this pass covers

- **Focus order** follows visual order through every state, and focus is never lost when a state
  changes. Moving from search to market detail to preview to confirmation must not dump focus
  back to the document body.
- **`aria-live` discipline.** Prices update on a poll. An `aria-live="polite"` region that
  announces every tick is worse than none at all — a screen reader user cannot work through a
  form that interrupts them every few seconds. Announce what changed *meaningfully*: a fill
  becoming unavailable, the gate firing, an error appearing. Not every price tick.
- **Contrast** meets WCAG AA, including the disabled CTA states and the "estimated" fee label.
  A label nobody can read is not a disclosure.
- **Skeletons match the final layout's dimensions**, so a load does not shift the page.
- **The golden path is completable by keyboard alone.** E4 built focus management in; verify it
  end to end and fix what is broken.
- **Empty and error copy review.** Every empty state says what to do next; no bare "no results".
  Every error says what actually happened, in the user's terms, and offers recovery where
  recovery exists.

## Run axe, and act on it

Wire `axe-core` into the Playwright or component tests and assert **no critical violations on
the golden path**. That assertion is an acceptance criterion, so it must run, not merely have
been run once by hand.

If a violation cannot be fixed without redesigning something, say so in the handoff rather than
suppressing the rule. A suppressed axe rule with no explanation is worse than a documented gap.

## Copy is bound by the claims policy

`docs/05-ai/EVALUATION.md` §B8 binds every word you touch. While you are in the copy:

- Nothing may state or imply the system beats the market.
- The simulated/real distinction must stay unambiguous wherever it appears.
- A fee from the category fallback stays labelled estimated.
- Do not soften an honest limitation into marketing.

## Acceptance criteria

1. Axe reports **no critical violations** on the golden path, asserted by a test that runs in CI.
2. The golden path is completable by keyboard alone, end to end.
3. Focus is never lost across a state transition.
4. Price polling does not spam an `aria-live` region.
5. Contrast meets WCAG AA, including disabled states and secondary labels.
6. Every empty and error state says what happened and what to do next.
